# Якорь

Читалка на русском языке: одно слово за раз, а средняя буква остаётся на одной вертикальной оси. Светлая и тёмная темы, мобильный интерфейс, локальная библиотека и четыре полных произведения Достоевского.

**Сайт:** https://peretyaginmstu-jpg.github.io/anchor-reader/

## Возможности

- EPUB, FB2, TXT, вставка текста. Для TXT доступны UTF-8 и Windows-1251; для FB2 учитывается объявленная кодировка.
- 100–1200 слов/мин, начальная скорость 300. Умные паузы после пунктуации, на длинных словах и между абзацами; их можно отключить.
- Неподвижная средняя буква: в словах чётной длины выбирается левая из двух средних букв. Unicode-графемы сохраняют комбинируемые ударения. Дефисное слово не разделяется.
- Смена размера букв, полноэкранное чтение и обычный текст. При слишком длинном слове размер автоматически уменьшается.
- Возврат на 10 слов, к началу фразы, по главам и по прогрессу; свободное перечитывание соседних абзацев. Выбор слова в контексте не запускает чтение автоматически.
- Необязательная остановка после абзаца. При скрытии вкладки чтение приостанавливается; возобновление вручную.
- Добровольная минипроба темпа: оригинальный текст и три вопроса. Результат относится только к этому отрывку; это не валидированный тест навыка и не обещание роста понимания.
- Сохранение книг, позиции и настроек в IndexedDB. Обновление позиции пишет только метаданные, не весь роман. Схема v2 мигрирует существующие данные v1 без сброса.

Загруженные пользователем файлы не отправляются на сервер. Встроенная классика загружается с этого же сайта и затем сохраняется в браузере. Очистка данных сайта удалит локальную библиотеку; синхронизации между устройствами нет. Сам сайт при первом открытии требует сеть — service worker для офлайн-запуска не установлен.

## Как пользоваться

1. Выберите книгу Достоевского на полке, нажмите «Открыть книгу» или «Вставить текст».
2. Выберите удобную скорость и нажмите «Читать». Держите взгляд рядом с красной буквой.
3. Пробел — старт/пауза; стрелки влево/вправо — соседние слова. При вводе текста, работе с ползунками и открытом диалоге эти горячие клавиши не вмешиваются.
4. Для перечитывания откройте «Абзац» или «Обычный текст». После выбора слова продолжите кнопкой «Продолжить».
5. «Подобрать темп» открывает отдельную минипробу, не меняющую позицию вашей книги.

## Локальный запуск

Сборка и установка npm-зависимостей не нужны. Требуются современный браузер и любой статический HTTP-сервер:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173/`. ES-модули и каталог книг требуют HTTP(S), а не открытия `index.html` через `file://`.

## Проверки

```sh
npm test
```

Node.js 22+ запускает тесты выбора якоря, таймера, Unicode и целостности встроенных книг. Для браузерных проверок откройте `/tests/browser.html` на локальном сервере и нажмите «Запустить проверки»: импорт, IndexedDB, миграция, сквозные сценарии, минипроба, неподвижность якоря на ширинах 320/390/1440 px. Временные записи теста удаляются, настройки восстанавливаются.

## Научное основание

Ускорение показа и понимание — разные величины. Поэтому приложение сохраняет свободный возврат к тексту, смысловые паузы и ручной выбор темпа. При включённых паузах оно показывает расчётный средний темп; в минипробе — фактический темп без времени остановок. Коэффициенты пауз и цвет буквы — настройки интерфейса, а не универсальные научные константы. См. [обзор исследований](docs/research.md).

## Устройство и ограничения

Статические HTML/CSS/JavaScript-модули. Нет аккаунтов, серверной обработки, аналитики, CDN и внешних шрифтов. `vendor/fflate.mjs` — fflate 0.8.2, лицензия MIT сохранена рядом.

Лимиты импорта: 30 МиБ на файл и 50 МиБ распакованного текста EPUB. Изображения из EPUB не распаковываются. DRM, PDF и сканы не поддерживаются. EPUB должен содержать корректный XML/XHTML; повреждённые старые HTML-книги могут быть отклонены. При ошибке текущая книга остаётся открытой. В браузере без доступного хранилища можно читать в памяти без сохранения.
